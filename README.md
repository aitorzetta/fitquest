# FitQuest V1

PWA gamificada para Aitor y Laura.

Incluye perfiles separados, peso y cintura, stats iniciales, XP semanal, bosses, quests, logros, Raid PortAventura, check-ins, progreso e importación/exportación de la partida.

## Datos
La V1 guarda la partida localmente en cada dispositivo mediante localStorage.
